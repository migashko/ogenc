# Список компиляторов для перегенерации (./ogenc).
#
# Можно указать несколько компиляторов, установленных в системе
# (g++ разных версий, clang++ и т.д.). Для каждого существующего
# бинарника ogenc снимет доступные флаги. По разнице между версиями
# списки предупреждений и оптимизаций режутся на слои: видно, в какой
# версии компилятора появилась опция (lists/ и cmake/ogenc/gen/).
#
# Это пути на конкретной машине, а не «официальная матрица поддержки».
# Несуществующие пути пропускаются — можно держать историю версий
# в этом файле, даже если часть компиляторов уже не установлена.
#
# Имеет смысл прогонять ./ogenc, пока предыдущий major ещё доступен:
# так новый слой получится аккуратным. Если оставить только текущие
# g++ и clang++, старые слои в репозитории не пропадут, но границу
# «появилось в 15, а не в 14» уже не снять.
#
# Пользователям ogenc как CMake-библиотеки этот файл не нужен.

/usr/bin/g++
/usr/bin/g++-4.8
/usr/bin/g++-4.9
/usr/bin/g++-5
/usr/bin/g++-6
/usr/bin/g++-7
/usr/bin/g++-8
/usr/bin/g++-9
/usr/bin/g++-10
/usr/bin/clang++
